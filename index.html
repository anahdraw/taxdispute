RSM Tax Dispute Simple Advisor

A prototype for tax dispute document extraction, comparable decision search, VAT regulation context, risk review, and taxpayer recommendation drafting.

Prototype Core

The full application is a Streamlit app designed for a serverful Python runtime with local SQLite and file upload support.

Vercel Shell

This Vercel deployment package provides a public landing page and a lightweight Python health endpoint.

Production Path

For a full Vercel-native app, migrate the UI to Next.js and move analysis, storage, and document processing into APIs and managed databases.

Check API Health GitHub: anahdraw

Do not commit API keys, taxpayer documents, local SQLite databases, or uploaded PDFs. This repository is configured to ignore those local artifacts by default.
