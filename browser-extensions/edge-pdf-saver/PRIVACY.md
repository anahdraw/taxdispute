# Kebijakan Privasi

PDF Saver untuk Edge tidak mengumpulkan, menyimpan, menjual, atau mengirim data pengguna ke server eksternal.

- `activeTab` dan `scripting` digunakan hanya setelah pengguna membuka popup, untuk mencari referensi PDF di tab aktif.
- `downloads` digunakan untuk memulai unduhan yang dipilih pengguna.
- `storage` digunakan hanya untuk menyimpan pilihan lokal mengenai dialog lokasi unduhan.

Ekstensi tidak meminta akses permanen ke semua situs dan tidak berusaha melewati kontrol akses, DRM, autentikasi, atau pembatasan server.
